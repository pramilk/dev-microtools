  - q: Will bookmarks, links and form fields still work in the merged PDF?
    a: Yes. Each file's bookmarks are copied and re-pointed at the right merged pages. Bookmarks for pages you left out are dropped.     a: Encrypted PDFs, meaning those with an open password or with permission restrictions, cannot be rewritten in a browser. They are flagged in the file list and left out of the merge. Open such a file in a PDF viewer, use "Print to PDF" to save an unprotected copy, and add that instead. Signed PDFs can be merged, but a digital signature only covers the exact original file, so it will not show as valid in the merged document. The tool warns you when that happens.

## Page ranges, rotation and order

Each file's **Pages** box takes a page selection in the order you want those pages to appear.
`1-3, 5` takes four pages, `8-` runs from page 8 to the end, `5-1` reverses the first five
pages, and `odd` or `even` pick alternating pages. That last option is handy for
interleaving the front and back sides of a single-sided duplex scan. The ↻ button rotates
all of that file's pages by 90° at a time, on top of any rotation they already had, which
fixes sideways scans without a separate tool.

## What a professional merge keeps

Many quick online mergers copy each page in isolation. That breaks links between pages,
discards bookmarks, and turns two copies of the same form into one field that shares a
single value. This tool copies each file's pages as a group, so links between pages land
on the merged copy of their target. Bookmarks are remapped, and named destinations are
rewritten so they keep working. Form field names are made unique whenever two files
collide. The merged file opens with its bookmarks panel showing, so readers can jump
straight to each original document. A digital signature is the one thing that cannot
survive: it certifies the exact bytes of the original file, so the tool warns you to keep
the signed original as well.

## What powers this tool

PDF parsing and writing use [`pdf-lib`](https://github.com/Hopding/pdf-lib) (MIT licensed),
in a background Web Worker that is only loaded once you add your first file. The preview is
your browser's own PDF viewer, so no PDF-rendering library is downloaded at all.
